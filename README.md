<img width="5220" height="316" alt="image" src="https://github.com/user-attachments/assets/173ca73d-c19f-440e-8f0b-944cfdc23145" /># project title : LegalEase:AI-Powered Legal Documentation Generator
LegalEase is an intelligent legal assistant that uses Google Gemini 1.5 Pro to generate professional legal documents instantly.
It creates contracts, NDAs, lease agreements, and employment letters based on user inputs like parties, terms, and effective dates.
LegalEase is built using Streamlit for the frontend, FastAPI for the backend, and Gemini AI for document generation. It ensures secure processing, editable previews, and multi-format downloads.
